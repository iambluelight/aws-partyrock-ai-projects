# 📊 AI Data Analysis Assistant

> **Project Type:** Generative AI Data Analysis Application  
> **Program:** AWS AI & ML Scholars Program

---

## Overview

The AI Data Analysis Assistant is a Generative AI application built using AWS PartyRock as part of the AWS AI & ML Scholars Program. The project demonstrates how Generative AI can analyze structured datasets, identify trends, summarize information, and generate meaningful insights through natural language prompts.

Rather than relying solely on manual analysis, the application uses prompt engineering to transform raw data into actionable insights, making data exploration faster, more efficient, and accessible to users without advanced programming or statistical knowledge.

---

## Project Objectives

- Analyze structured datasets using Generative AI.
- Generate meaningful insights from real-world data.
- Demonstrate practical prompt engineering techniques.
- Present AI-generated findings in a clear and understandable format.
- Explore how Generative AI can support data-driven decision-making.

---

## Dataset

**Body Measurements Dataset (BodyM)**

The dataset contains human body measurements, including height and body circumference measurements, allowing the AI assistant to identify relationships, trends, and patterns within the data.

---

## Key Insights Generated

The AI assistant successfully generated several meaningful insights, including:

- The average height in the dataset is **172.15 cm**, with values ranging from **140.86 cm to 197.51 cm**.
- The dataset revealed three common body shapes:
  - Pear-shaped
  - Balanced
  - Apple-shaped
- Waist measurements showed the highest variability, while height remained the most consistent measurement.
- Skeletal proportions remained relatively uniform across the population, while body composition varied significantly.
- Frame size appeared genetically consistent, whereas circumference measurements reflected differences in body mass and fitness levels.

---

## Prompt Engineering

The following prompts produced the most valuable insights:

- What is the average height and weight?
- Are there correlations between different measurements?
- What trends or patterns can you identify?
- Generate an analysis table based on the data.

This project demonstrated how prompt quality directly influences the quality and relevance of AI-generated insights.

---

## Accuracy & Limitations

### Accuracy

The AI-generated analysis closely aligned with the dataset and produced logical, data-supported observations.

### Limitation

The quality of the generated insights depended heavily on the quality of the prompts provided. Well-structured prompts produced detailed and relevant analysis, while poorly written prompts resulted in incomplete or less useful outputs.

This reinforced the importance of effective prompt engineering when working with Generative AI.
